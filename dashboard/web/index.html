    Where the settings come from

    1. Saved hereStored in data/ai_settings.json on the server (git-ignored). Wins over everything else.
    2. .env fileLLM_PROVIDER, LLM_MODEL and LLM_API_KEY, or real environment variables. Used when nothing is saved here.
    3. DefaultWithout any key, the assistant still answers from its built-in rules.

    Anyone who can open this dashboard can change these settings, so only expose it on a network you trust. Only summary numbers are sent to the AI service, never IPs, evidence or logs.

    Clear all events?

    This deletes every logged event and resets rate limits. It cannot be undone.
